# The Excuse That Almost Works

One line a gamer texts the boss to skip work during GTA 6 launch week.

## The excuse

> Sorry, landlord's doing the annual gas safety check this morning and someone has to be in

16 words, 89 characters, one line of plain text.

## Run

```sh
node main.ts
```

Writes the excuse to `output/entry.txt` (and to `/output/entry.txt`
when run inside the make.fun sandbox).
